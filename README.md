# design-starter

Mal-repo med [Open Design Agent Kit](https://github.com/feimacode/open-design-agent-kit) forhåndsinstallert for Claude Code.

- `.claude/skills/` – designskills som aktiveres på designforespørsler
- `.mcp.json` – registrerer MCP-serveren `open-design` (hentes via `npx`)

Bruk: «Use this template» → åpne det nye repoet i Claude Code → be om en landingsside, deck, dashboard osv.

Oppdatere: kjør `npx @feimacode/open-design-agent-kit init --tools claude` på nytt.
